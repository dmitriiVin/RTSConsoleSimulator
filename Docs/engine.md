# Engine

Документ описывает устройство движка как набора базовых подсистем без погружения в детали реализации.

## Состав

```text
Engine
   ├── Core
   ├── Camera
   ├── Math
   ├── Render
   └── Modules
```

## Core

- `EngineConfig.h` — общие константы проекта.
- `Time/EngineTime.*` — delta time, elapsed time и FPS.

## Camera

- `Camera.*` — позиция камеры, движение и ограничение по карте.

## Math

- `Isometric.*` — преобразование координат мира в экранные.
- `ScreenPoint.h` — вспомогательная точка для экранных координат.

## Render

- `SDLRender.*` — создание окна, рендерера и главный цикл вывода.

## Modules

- Подсистемы уровня движка, которые можно расширять отдельно от ядра.

## Граница ответственности

Движок отвечает за инфраструктуру. Игровые правила, сценарии и конкретные сущности остаются в `Game`.

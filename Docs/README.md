# Документация RTSEngine

Добро пожаловать в документацию RTSEngine.

## Содержание

- architecture.md — архитектура проекта.
- roadmap.md — план развития движка.
- engine.md — устройство движка.
- tilemap.md — модуль TileMap.
- render.md — система рендера.
- math.md — математические преобразования.
- game.md — взаимодействие игры с движком.
- coding-style.md — правила оформления кода.

## Как пользоваться

Сначала откройте architecture.md, затем переходите к документам по конкретным подсистемам. Roadmap удобно использовать как список текущего прогресса и ближайших задач.

## Изображения

В папке images хранятся схемы архитектуры и диаграммы модулей.
